# Utkarsh Singh — Portfolio

A single-page portfolio for Utkarsh Singh, an Electronics & Communication Engineering student at JIIT Noida. It presents selected web, cybersecurity, and embedded-systems work in a dark, editorial-style interface with motion-led interactions.

## Tech stack

- React 19, TypeScript, and Vite
- React Router
- Tailwind CSS
- Framer Motion and GSAP / ScrollTrigger
- `hls.js` for the streamed hero video
- Vercel Analytics
